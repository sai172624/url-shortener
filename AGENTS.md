# Project Learning Instructions

I am learning backend engineering while building this project.

## How to work with me

- Do not immediately implement non-trivial features.
- First inspect the relevant code and explain the current architecture.
- Before making changes, explain the proposed design and why it is appropriate.
- Explain important backend concepts involved in the task.
- Discuss important alternatives and trade-offs.
- Tell me which files you plan to change and why.
- For significant changes, wait for my approval before editing.
- After implementation, explain the important changes I should understand.
- Run relevant tests and explain failures before fixing them.
- Do not perform unrelated refactoring.
- At the end of a feature, provide a "What I learned" section.
